# Gamil CloudPool — منصة تجميع وإدارة التخزين السحابي الموحد (مجانية ومفتوحة المصدر 100%)

منصة موحدة لإدارة وتجميع عدة حسابات **Google Drive** وعقد التخزين المحلية ضمن واجهة افتراضية واحدة (**Union Virtual Filesystem**)، مبنية بالكامل على تقنيات مجانية ومفتوحة المصدر (**FastAPI + SQLite FTS5 + Cryptography AES-256-GCM + Rclone Union/Chunker Generator**).

---

## المميزات الأساسية المنفذة في البرنامج

1. **ربط وتجميع عدة حسابات Google Drive وعقد تخزين (`Union Pool`):**
   - دمج منطقي لعدة حسابات في شجرة مجلدات موحدة (`/كتب`، `/تسجيلات وميديا`، `/تقارير ومستندات NG Academy`، `/Google AI Studio`).
   - مزامنة أولية حقيقية لبيانات حساب `ngacademy14@gmail.com` المتصل مع دعم ربط عدد غير محدود من الحسابات الإضافية.
2. **محرك التوزيع الذكي التلقائي (`Smart Placement Engine`):**
   - يدعم سياسات `Rclone Union` القياسية:
     - `mfs` (**الأكثر مساحة فارغة — Most Free Space**).
     - `epmfs` (**الحفاظ على المسار مع الأكثر مساحة فارغة — Existing Path MFS**).
     - `lno` (**الأقل عددًا في الملفات — Least Number of Objects**).
     - `priority` (**الأولوية المتدرجة مع عتبة تحذير 80%**).
   - يراعي تلقائيًا هامش الأمان (`Safety Buffer`) وسقف الرفع اليومي لحسابات Google Drive (`750 GB / 24h`).
3. **منع واكتشاف التكرار بالبصمة الرقمية (`MD5 Deduplication`):**
   - **حماية استباقية قبل الرفع (`Pre-Upload Dedupe`):** يحسب بصمة `MD5` للملف قبل رفعه ويقارنها بفهرس `SQLite` عبر جميع الحسابات لمنع استهلاك المساحة مرتين.
   - **ماسح تكرار شامل (`Global Dedupe Scanner`):** يكتشف الملفات المتطابقة بالبصمة الرقمية داخل الحساب الواحد وعبر الحسابات المختلفة حتى لو اختلفت أسماؤها، مع تنظيفها واسترجاع المساحة بضغطة زر.
4. **موازنة المساحة التلقائية (`Auto-Rebalance Pool`) والنقل العابر للحسابات:**
   - إمكانية نقل أي ملف من حساب ممتلئ إلى حساب فارغ بضغطة زر مع بقاء الملف في نفس مساره الافتراضي داخل الواجهة الموحدة.
5. **خزنة تشفير آمنة لرموز OAuth 2.0 (`AES-256-GCM Token Vault`):**
   - لا يتم حفظ أي كلمات مرور؛ جميع رموز `access_token` و`refresh_token` مشفرة بمعيار `AES-256-GCM` مع إمكانية تجديد الرموز دوريًا دون الحاجة لإعادة تسجيل الدخول.
6. **مولّد إعدادات `rclone.conf` و`OpenList` المدمج:**
   - يولّد تلقائيًا ملف `rclone.conf` جاهز للعمل مع أوامر `rclone mount` (لتركيب المساحة الموحدة كقرص محلي افتراضي مثل Mountain Duck مجانًا) و`rclone serve webdav` و`rclone rcd`.
7. **الواجهة الموحدة المبسطة (`Simple Unified Mode`) ومحرك التوسع التلقائي الخلفي (`Background Auto-Scaler`):**
   - واجهة رسومية مبسطة واحدة تعرض للمستخدم فقط السعة الإجمالية، المساحة المستخدمة، وشريط التقدم اللحظي لرفع الملفات.
   - عند امتلاء الحساب الحالي (15 GB) أثناء الرفع، يقوم النظام تلقائيًا في الخلفية بملء المساحة المتبقية ثم استدعاء موصلات التوسع (`Standby Pool` / `GAMADV-XTD3` / `Casdoor IAM` / `Stalwart` / `Rclone Provisioner`) لتوليد أو تفعيل حساب جديد (+15 GB) واستئناف رفع بقية الملف بسلاسة دون فقدان أي بيانات.
